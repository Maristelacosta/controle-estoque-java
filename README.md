# 📦 Controle de Estoque em Java

## 🚀 Sobre o Projeto

O **Controle de Estoque em Java** é um sistema desenvolvido para gerenciar produtos, controlar entradas e saídas de mercadorias e monitorar os níveis de estoque de forma eficiente.

Este projeto foi criado com o objetivo de aplicar conceitos de **Programação Orientada a Objetos (POO)**, lógica de programação, modelagem de sistemas e boas práticas de desenvolvimento utilizando Java.

---

## 🎯 Funcionalidades

✅ Cadastro de produtos

✅ Atualização de estoque

✅ Controle de entradas de mercadorias

✅ Controle de saídas de produtos

✅ Consulta de produtos cadastrados

✅ Busca por código ou nome

✅ Relatórios de estoque

✅ Validação de dados

## 📌 Regras de Negócio

- Cada produto deve possuir um código único.
- Não é permitido estoque negativo.
- O sistema deve registrar todas as movimentações de entrada e saída.
- O estoque disponível deve ser atualizado automaticamente.
- Os dados cadastrados devem ser validados antes do processamento.
