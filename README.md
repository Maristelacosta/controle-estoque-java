# 📦 Controle de Estoque em Java

## 🚀 Sobre o Projeto

Sistema desenvolvido em Java para gerenciamento de estoque, permitindo o cadastro de produtos, controle de entradas e saídas, consulta de itens e monitoramento da quantidade disponível.

Este projeto foi criado com o objetivo de praticar Programação Orientada a Objetos (POO), lógica de programação e desenvolvimento de sistemas de gestão.

## 🎯 Funcionalidades

- Cadastro de produtos
- Atualização de estoque
- Controle de entradas
- Controle de saídas
- Consulta de produtos
- Busca por código
- Relatórios de estoque
- Validação de dados

## 🛠 Tecnologias

## 📌 Regras de Negócio

- Cada produto possui um código único.
- Não é permitido estoque negativo.
- O sistema registra entradas e saídas.
- Deve haver controle da quantidade disponível.
