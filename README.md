# 📦 Controle de Estoque em Java

## 🚀 Sobre o Projeto

O Sistema de Controle de Estoque é uma aplicação desenvolvida em Java para auxiliar no gerenciamento de produtos, entradas, saídas e monitoramento de estoque.

O objetivo do projeto é aplicar conceitos de programação orientada a objetos, estrutura de dados, lógica de negócio e boas práticas de desenvolvimento de software.

---

## 🎯 Funcionalidades

- Cadastro de produtos
- Atualização de estoque
- Controle de entradas e saídas
- Consulta de produtos cadastrados
- Busca por código ou nome
- Relatórios de estoque
- Validação de dados

## 📌 Regras de Negócio

- Não permitir estoque negativo.
- Produto deve possuir código único.
- Quantidade mínima de estoque configurável.
- Registrar movimentações de entrada e saída.
